# 📈 주식 계절성 탐색기 (stock-seasonality)

미국 주식의 **월별 계절성**(매년 특정 달에 반복적으로 오르거나 내리는 패턴)을 찾아주는 도구입니다.
차트 이미지를 읽는 대신 **가격 데이터(숫자)를 직접 받아 통계로 판단**하고, 결과를 차트로 보여줍니다.

- 데이터: 야후 파이낸스 (`yfinance`), 상장일부터 전체 기간 일봉, 배당·분할 반영 수정주가
- 대상: 나스닥 100, 나스닥 전체, 미국 전체(나스닥 + NYSE 등), 직접 입력한 종목
- 화면: Streamlit 웹 앱 + 터미널 스캐너

## 차트 패턴 리포트 + 유사 종목 찾기

특정 종목(예: HHH, KRUS)의 차트 흐름을 1개월·3개월·1년·3년·5년 기준으로 분석하고,
**언제 오르고 언제 내리는지** 비슷한 종목을 미국 전체에서 찾습니다.

```bash
python analyze.py HHH KRUS                               # 리포트만 (reports/report.html)
python analyze.py HHH KRUS --similar                     # + 미국 전체에서 유사 종목 (처음엔 15분 정도)
python analyze.py HHH KRUS --similar --excess            # 소형주 지수(IWM) 흐름을 뺀 고유 패턴 기준
```

리포트에 들어가는 것:
- 자동 요약: 강한 달·약한 달, 저점·고점이 자주 나온 달, 상승·하락 구간 평균 기간과 폭, RSI 계절성,
  실적 발표 전후 흐름, 시장(IWM)과의 관계, 현재 위치
- 기간별 요약 표 (1개월 ~ 5년): 수익률, 최대낙폭, 최고·최저가 날짜, RSI 범위, 과매수·과매도 일수
- 가격 + RSI 차트 (고점 ▼ · 저점 ▲ · 실적일 점선, 1개월~5년 버튼)
- 연도별 흐름 겹쳐보기, 월별 평균 수익률, 월별 저점·고점 횟수, 매달 초 매수 시 1·3개월 후 수익률, 월별 RSI, 실적 반응
- 유사 종목 표: 유사도(월별·주별 계절성 지문의 상관), 계절 진폭, 해마다 일치 비율

웹 앱의 **차트 패턴**, **유사 종목 찾기** 탭에서도 같은 내용을 볼 수 있습니다.

### 용어

- **스윙(고점·저점)**: 그 뒤로 일정 % 이상 되돌린 꼭지·바닥. 기준 %는 종목 변동성에 맞춰 자동으로 정합니다
  (월 변동성의 1.5배, 8~35%).
- **계절성 지문**: 최근 N년의 월별(12개)·주별(52개) 평균 수익률에서 전체 평균을 뺀 모양.
  꾸준한 상승 추세는 빠지고 "어느 시기에 상대적으로 강하고 약한지"만 남습니다.
- **해마다 일치**: 최근 N년 중 그 해의 월별 흐름이 기준 종목 패턴과 같은 방향이었던 해의 비율.
  유사도가 높아도 이 값이 낮으면 한두 해의 큰 움직임 때문에 비슷해 보이는 것입니다.

## 실적 주기 패턴이 비슷한 종목 찾기 (KRUS 같은 종목)

달력(몇 월)이 아니라 **분기 실적 발표 때 크게 출렁이는** 종목을 찾습니다.

```bash
python earnings_scan.py KRUS --validate                       # 나스닥, 시총 $3억↑, 거래대금 $500만↑, 주가 $5↑
python earnings_scan.py KRUS --exchanges us --validate        # 나스닥 + NYSE
python earnings_scan.py KRUS --min-mcap 1e9 --min-dollar-volume 2e7   # 더 큰 종목만
```

- 종목 목록과 시총·거래대금은 야후 스크리너에서 한 번에 받고, 실적 발표일은 종목별로 받아 `data/earnings/` 에 저장합니다
  (처음 1회 나스닥 약 5분, 미국 전체 약 10분).
- 비교 항목: 실적 반응 크기(평소 대비 배수), 1년 출렁임 중 실적 3일 비중, 고점·저점과 실적일 일치, 실적 전 상승 확률, 변동성.
- `--validate`: 2년 전까지 데이터로만 고른 상위 20개가 최근 2년에도 같은 성격을 유지했는지 확인합니다.

## 박스권 왕복 종목 찾기

같은 가격 범위 안에서 위아래로 여러 번 오가는 종목 (KRUS 의 2021~2025 같은 모양).

```bash
python range_scan.py --validate                 # 미국 전체, 최근 5년, 3 왕복 이상
python range_scan.py --years 3                  # 최근 3년
python range_scan.py --min-band 2 --min-legs 8  # 더 크게, 더 자주 왕복
python range_scan.py --years 3,4,5 --min-legs 4 --bottom   # 지금 박스 하단 근처인 종목만
```

박스 = 주봉 종가 하위 10%~상위 10% 가격대. 박스 하단(아래 20%)↔상단(위 20%) 횡단 횟수, 추세 없음,
고점·저점 높이가 일정한지로 점수를 매기고, 차트에 박스(노란 띠)와 현재 위치(박스 아래/하단/중간/상단/위/이탈)를 표시합니다.

> 검증: 2021.9~2024.9 로 찾은 박스형은 이후 2년 동안 같은 폭의 다른 종목보다 박스 안 왕복이 약 2배 많았지만(0.77회 vs 0.40회),
> 박스를 벗어나는 비율은 비슷했습니다. 박스는 언제든 깨질 수 있습니다.

## 매집 흔적 스캐너 (+ 백테스트)

주가·거래량에 남는 매집 흔적(주가 대비 거래량 쏠림, CMF, 흡수형 대량거래, 변동성 수축)과
기관 보유 변화·내부자 매수·공매도 비율로 후보를 뽑고, 같은 방법이 과거에 통했는지 검증합니다.

```bash
python accumulation_scan.py --backtest                  # 나스닥
python accumulation_scan.py --exchanges us --backtest   # 나스닥 + NYSE
```

> 2022.11~2026.6 검증 결과 이 흔적들은 이후 3개월 수익률을 예측하지 못했습니다 (상위 30개가 시장보다 −0.5~−1.1%).
> 2025.1~2026.6 내부자 장내 매수 1,986건도 이후 성과가 정확히 평균이었습니다. 후보 목록은 참고용입니다.

## 미국 중간선거 전후 주가

```bash
python midterm_report.py          # S&P 500·나스닥·러셀2000·다우, 1950년 이후 중간선거
python midterm_report.py --refresh
```

선거일(11월 첫 월요일 다음 화요일) 기준 6개월 전~1년 후 구간 수익률, 중간선거 해 최대낙폭과 저점,
선거 전후 변동성·VIX, 오늘 시점에서 샀을 때의 과거 결과, 같은 날짜의 다른 해와 비교를 리포트로 만듭니다.

## 사용법

### 웹 앱

```bash
streamlit run app.py
```

브라우저가 열리면:
- **종목 분석** 탭: 종목 코드 입력 → 월별 평균 수익률(★ = 유의미), 연도별 가격 흐름(연초=100), 월별 상승 확률, 연도×월 히트맵
- **스캐너** 탭: 나스닥 100 전체를 스캔해서 계절성이 강한 (종목, 월) 순위
- 사이드바: 분석 기간(1년/5년/10년/20년/전체), QQQ 대비 초과수익 보기, 판정 기준 조정
- 인터넷이 안 될 때는 **데모 데이터 사용**을 켜면 가짜 데이터로 화면을 확인할 수 있습니다.

### 터미널 스캐너

```bash
python scan.py                                  # 나스닥 100, 전체 기간
python scan.py --years 10 --top 30              # 최근 10년 기준 상위 30개
python scan.py --excess                         # QQQ 대비 초과수익 기준
python scan.py --strict                         # 다중검정 보정(q값)까지 통과한 것만
python scan.py --tickers AAPL NVDA TSLA         # 지정 종목
python scan.py --universe nasdaq --min-dollar-volume 5e6   # 나스닥 전체 (처음엔 1시간 이상)
python scan.py --refresh                        # 캐시를 오늘까지 업데이트
python scan.py --demo                           # 네트워크 없이 동작 확인
```

전체 결과는 `results/scan.csv` 에 저장됩니다.

## 데이터 저장 방식

- 처음 실행할 때 종목별 전체 기간 일봉을 받아 `data/prices/<종목>.parquet` 에 저장합니다.
  (나스닥 100 기준 수 분, 수십 MB)
- 이후에는 캐시를 그대로 쓰고, `--refresh` 를 주면 **마지막 날짜 이후만** 받아 이어 붙입니다.
  배당·분할로 과거 수정주가가 바뀐 종목은 자동으로 전체를 다시 받습니다.
- 50개씩 나눠 받고, 중간에 끊겨도 다시 실행하면 받은 종목은 건너뜁니다.
- `data/` 는 용량 때문에 Git 에 올리지 않습니다.

## 계절성 판정 방법

1. 월말 종가로 월 수익률을 계산하고 "연도 × 월" 표를 만듭니다. (진행 중인 이번 달은 제외)
2. 각 달에 대해 다음을 계산합니다.
   - **평균 / 중앙값 수익률**
   - **다른 달 대비**: 그 달 평균 − 나머지 달 평균
   - **적중률**: 상승 패턴이면 그 달에 실제로 오른 해의 비율, 하락 패턴이면 내린 해의 비율
   - **p값**: 그 달 수익률이 나머지 달과 다른지 (Welch t-검정)
3. 아래를 **모두** 만족하면 유의미한 계절성(★)으로 판정합니다.
   - 표본 8년 이상
   - p < 0.05
   - 적중률 70% 이상
   - 최근 5년에도 같은 방향 (패턴이 최근에도 유지)

> **왜 0% 가 아니라 "다른 달"과 비교하나요?**
> 꾸준히 오르는 종목은 모든 달의 평균이 플러스라서, 0% 와 비교하면 모든 달이 "유의미한 상승"으로 나옵니다.
> 그건 상승 추세지 계절성이 아닙니다. 다른 달보다 확연히 강하거나 약한 달만 계절성으로 봅니다.

### 주의할 점

- **다중검정 문제**: 100종목 × 12개월 = 1200번 검정하면 우연히 p<0.05 가 나오는 경우가 수십 개 생깁니다.
  스캐너의 **q값**(Benjamini-Hochberg 보정)이 0.05 미만인 것이 더 믿을 만합니다 (`--strict`).
- **생존 편향**: 상장폐지된 종목은 데이터가 없어서 분석에서 빠집니다.
- **1년, 5년 기간**은 같은 달 표본이 1~5개뿐이라 통계 판정이 나오지 않습니다. 차트로 흐름만 참고하세요.
- 과거 패턴이 미래 수익을 보장하지 않습니다. 투자 판단의 참고 자료로만 쓰세요.

```
app.py                     Streamlit 웹 앱
scan.py                    터미널 스캐너 (월별 계절성)
analyze.py                 차트 패턴 리포트 + 유사 종목 찾기
earnings_scan.py           실적 주기 패턴이 비슷한 종목 찾기
accumulation_scan.py       매집 흔적 스캐너 + 백테스트
range_scan.py              박스권 왕복 종목 찾기
midterm_report.py          미국 중간선거 전후 주가 리포트
src/seasonality/
  data.py                  다운로드 + parquet 캐시 + 증분 업데이트
  universe.py              나스닥 100 목록, 나스닥 전체 목록 받기
  analysis.py              월 수익률, 월별 통계, 계절성 판정, 연도별 경로
  scanner.py               여러 종목 스캔, 다중검정 보정(q값)
  patterns.py              RSI, 고점·저점(스윙), 매수 시점별 수익률, 기간별 요약, 유사 종목 찾기
  earnings.py              실적 발표일, 실적 전후 반응
  report.py                자동 요약 문장 + HTML 리포트
  charts.py                Plotly 차트 (상승 = 빨강, 하락 = 파랑)
  synthetic.py             테스트·데모용 가짜 주가
tests/                     pytest (네트워크 없이 실행)
```
